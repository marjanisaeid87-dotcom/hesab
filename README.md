# حساب شخصی — راهنمای راه‌اندازی (حدود ۱۵ دقیقه، رایگان)

برنامه دو بخش دارد:

- **Supabase** (رایگان): دیتابیس و سیستم ورود. داده‌های شما اینجا ذخیره می‌شود.
- **GitHub Pages** (رایگان): میزبانی خود صفحه وب. بعد از راه‌اندازی، یک آدرس مثل `https://نام‌کاربری.github.io/hesab` دارید که از هر دستگاهی باز می‌شود.

> 💡 قبل از راه‌اندازی می‌توانید `index.html` را باز کنید و دکمه «ورود نمایشی» را بزنید تا برنامه را ببینید.

---

## مرحله ۱ — ساخت پروژه در Supabase

1. به [supabase.com](https://supabase.com) بروید و با حساب GitHub یا ایمیل ثبت‌نام کنید.
2. **New project** را بزنید. یک نام (مثلاً `hesab`) و یک رمز قوی برای دیتابیس بدهید (این رمز را جایی نگه دارید؛ برای ورود به برنامه نیست). Region را **Frankfurt (eu-central-1)** انتخاب کنید.
3. چند دقیقه صبر کنید تا پروژه آماده شود.

## مرحله ۲ — ساخت جدول‌ها

1. از منوی چپ **SQL Editor** را باز کنید → **New query**.
2. کل محتوای فایل `schema.sql` را کپی و Paste کنید و **Run** را بزنید.
3. باید پیام `Success` ببینید.

## مرحله ۳ — ساخت کاربر خودتان و بستن ثبت‌نام

1. **Authentication → Users → Add user → Create new user**
   - ایمیل و یک **رمز قوی** (حداقل ۱۲ کاراکتر، ترکیب حروف و عدد و علامت) وارد کنید.
   - تیک **Auto Confirm User** را بزنید.
2. **Authentication → Sign In / Providers** (یا Settings): گزینه **Allow new users to sign up** را **خاموش** کنید.
   این کار مهم است: بعد از آن هیچ‌کس جز شما نمی‌تواند حساب بسازد.

## مرحله ۴ — وصل کردن برنامه به Supabase

1. **Project Settings → API Keys** (یا Data API) را باز کنید.
2. **Project URL** و کلید **anon public** (یا **publishable**) را کپی کنید.
3. فایل `config.js` را با Notepad باز کنید و این دو مقدار را جایگزین کنید:

```js
window.APP_CONFIG = {
  SUPABASE_URL: "https://abcdxyz.supabase.co",
  SUPABASE_ANON_KEY: "eyJhbGciOi...",
};
```

> ⚠️ فقط کلید **anon/publishable** را بگذارید؛ هرگز `service_role` یا `secret`.

## مرحله ۵ — انتشار روی اینترنت با GitHub Pages

1. در [github.com](https://github.com) حساب بسازید (اگر ندارید).
2. **New repository** → نام `hesab` → حالت **Public** → Create.
   (فقط کد برنامه عمومی است؛ داده‌های مالی شما در Supabase و پشت رمز عبور است.)
3. در صفحه مخزن **uploading an existing file** را بزنید و **همه فایل‌های این پوشه** را بکشید و رها کنید → **Commit changes**.
4. **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main` و پوشه `/ (root)` → Save.
5. بعد از ۱–۲ دقیقه آدرس سایت بالای همان صفحه نمایش داده می‌شود.

## مرحله ۶ — استفاده روی دستگاه‌ها

- **گوشی:** آدرس را در Chrome (اندروید) یا Safari (آیفون) باز کنید → منو → **Add to Home screen**. مثل یک اپ نصب می‌شود.
- **لپ‌تاپ شخصی:** هنگام ورود تیک «مرا به خاطر بسپار» را بزنید.
- **سیستم شرکت و سازمان:** تیک «مرا به خاطر بسپار» را **نزنید**؛ با بستن مرورگر خارج می‌شوید. خروج خودکار بعد از ۱۵ دقیقه عدم فعالیت هم فعال است (در تنظیمات قابل تغییر).

## امنیت برنامه

| لایه | توضیح |
|---|---|
| ورود با ایمیل و رمز | سیستم Auth خود Supabase؛ رمز به‌صورت هش ذخیره می‌شود. |
| بسته بودن ثبت‌نام | فقط کاربری که خودتان ساخته‌اید وارد می‌شود. |
| Row Level Security | حتی با داشتن کلید عمومی، بدون ورود هیچ داده‌ای خوانده نمی‌شود و هر کاربر فقط ردیف‌های خودش را می‌بیند. |
| ارتباط HTTPS | همه ارتباط‌ها رمزنگاری‌شده است. |
| محدودیت تلاش ورود | بعد از ۵ تلاش اشتباه، یک دقیقه قفل (به‌علاوه محدودیت سمت سرور Supabase). |
| خروج خودکار و «مرا به خاطر بسپار» | برای سیستم‌های مشترک. |
| Content-Security-Policy | جلوی اجرای کد ناشناس در صفحه را می‌گیرد. |

## نکات مهم

- **پروژه رایگان Supabase اگر ۷ روز هیچ استفاده‌ای نشود، متوقف (Pause) می‌شود.** با استفاده روزانه مشکلی پیش نمی‌آید. اگر متوقف شد، وارد داشبورد Supabase شوید و **Restore** بزنید؛ داده‌ها حفظ می‌شوند.
- نسخه رایگان پشتیبان قابل دانلود ندارد؛ ماهی یک بار از **تنظیمات → پشتیبان کامل (JSON)** خروجی بگیرید.
- ممکن است در بعضی شبکه‌ها (به‌خصوص اینترنت سازمانی) دسترسی به `supabase.co` یا `github.io` محدود باشد و به VPN نیاز داشته باشید.
- برای تغییر رمز: داخل برنامه → تنظیمات → تغییر رمز عبور.
- اگر رمز را فراموش کردید: Supabase → Authentication → Users → روی کاربر → **Reset password** یا ساخت رمز جدید.

## فایل‌ها

| فایل | کاربرد |
|---|---|
| `index.html`، `app.js`، `style.css` | خود برنامه |
| `config.js` | آدرس و کلید Supabase (فقط این فایل را ویرایش کنید) |
| `supabase.js` | کتابخانه رسمی Supabase (نسخه 2.118.0، محلی تا به CDN وابسته نباشد) |
| `schema.sql` | ساختار دیتابیس و قوانین امنیتی |
| `manifest.json`، `sw.js`، `icon.svg` | قابلیت نصب روی گوشی |
